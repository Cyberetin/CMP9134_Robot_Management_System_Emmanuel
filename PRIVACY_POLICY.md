What data are you collecting?

To make sure that everything is being watched and held accountable, the system gathers a number of important bits of information. This contains the person's username who is controlling the robot, the IP address from which the connection is made, and exact times that show when each session starts and ends. The system also keeps track of every command delivered to the robot, such as directions for movement, tasks to be done, and any changes to the robot's settings while it is working.

Why are you collecting it?

The major reason for collecting this data is to make sure there is a clear audit trail and keep operations safe. We can make sure that only authorized people are using the equipment by keeping track of who is controlling the robot and when. If there is an accident, a malfunction, or something unexpected happens, the command logs are very important for finding out what went wrong and whether it was the operator's mistake or a problem with the system. Keeping these extensive records also makes sure that you follow safety rules and audit standards in your field, giving you confirmation that you are managing the system responsibly.

How are you protecting it?

Access to this private information is tightly regulated and secured by several layers of protection. Only users with the "Auditor" role can see the logs. This makes sure that operational data is not available to regular users or the public. All data is kept safe in an encrypted database that can only be accessed with a password and strong authentication methods. There are no public-facing access points to the log data in the system, and all transmissions are secure so that they can't be intercepted or viewed without permission while they're being sent.
